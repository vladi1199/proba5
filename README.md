# Filstar — наличности за nasluka99.com

Сваля наличностите и цените от filstar.com и ги качва като XML, който
магазинът чете.

## За този, който ще го пуска

**Не ви трябва Python и не ви трябва GitHub.**

Свалете готовата програма от **[Releases](../../releases/latest)**, разархивирайте,
пуснете VPN и щракнете два пъти върху `Обнови наличностите.bat`
(или `obnovi-nalichnostite.command` на Mac).

Подробно: [RUN.md](RUN.md)

## За разработчик

| файл | какво е |
|---|---|
| `filstar_local.py` | скриптът — сваля, чете наличност по вариант, пише CSV и XML, качва в GitHub |
| `all_skus.csv` | 6710 SKU-та (обединени от proba4 и proba5); 6709 от тях съществуват в магазина |
| `settings.ini.example` | шаблон за токена; преименува се на `settings.ini` |
| `RUN.md` | инструкции и защо се пуска локално |
| `.github/workflows/build-exe.yml` | прави .exe за Windows и приложение за Mac |
| `proba5/` | старият скрипт — вече не работи, оставен за история |

**Пуска се локално, не в GitHub Actions**, защото Cloudflare на filstar.com
блокира IP адресите на GitHub. Проверено — включително с истински браузър.
Обяснението е в [RUN.md](RUN.md).

Старият `daily_update.yml` е спрян по график (може да се пусне ръчно).
`proba4` продължава да работи като резервен вариант, но дава наличност само
на ниво продукт, не на вариант.
